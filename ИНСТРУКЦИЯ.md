# Как опубликовать проект на Amvera (задание 8)

Проект уже подготовлен: исправлен server.js, добавлены amvera.yml и .gitignore,
таблица students создаётся в БД автоматически при запуске сервера.

## 1. Залить проект на GitHub (Git Bash, в папке project6)

1. Создайте на GitHub пустой репозиторий (без README, .gitignore и license), например Project6.
2. В Git Bash выполните:

```bash
cd "путь/к/папке/project6"
git config --global user.name "ВАШ_НИК_GITHUB"
git config --global user.email "ваша@почта"
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/Project6.git
git push -u origin main
```

Ошибка 403 «denied to чужой_ник»: Win+R → control keymgr.dll → удалить записи git:https://github.com,
либо `git -c credential.helper= push https://ВАШ_НИК@github.com/ВАШ_НИК/Project6.git main`
(пароль = Personal Access Token с галочкой repo).

## 2. Создать базу данных MySQL на Amvera

1. Зарегистрируйтесь на amvera.ru → «Создать» → тип «Преднастроенный сервис» / «База данных» → MySQL.
2. Задайте имя (например studentsdb), имя базы StudentsDB, пользователя и пароль — запишите их.
3. После запуска откройте карточку БД → «Инфо» и скопируйте **внутреннее доменное имя**
   (вида `amvera-ваш_логин-run-studentsdb`).

## 3. Создать приложение на Amvera

1. «Создать приложение» → окружение Node.js, toolchain npm, версия 20.
2. Источник кода: GitHub → ваш репозиторий Project6, ветка main
   (конфигурация берётся из файла amvera.yml, он уже в проекте).
3. В карточке приложения → «Переменные» добавьте:

| Имя | Значение |
|---|---|
| PORT | 3000 |
| HOST_DB | внутреннее доменное имя БД из шага 2 |
| PORT_DB | 3306 |
| USER_DB | пользователь БД |
| PASSWORD_DB | пароль БД (лучше как «секрет») |
| NAME_DB | StudentsDB |

4. Нажмите «Собрать» и дождитесь `Container builder has completed with exit code: 0`.
5. В логах приложения должно быть:
   - `Сервер запущен на http://localhost:3000`
   - `Подключение к БД успешно, таблица students готова`
   Если вместо второй строки «Ошибка подключения к БД» — проверьте переменные и перезапустите приложение.
6. «Домены» → убедитесь, что бесплатный домен добавлен и привязан к приложению.
   Откройте сайт кнопкой «Открыть приложение».

## 4. Проверка

Добавьте студента — он появится в таблице «Список студентов (из БД)» внизу страницы.
Отредактируйте его по ID, затем удалите. Ссылку на сайт отправьте преподавателю.

## Обновление сайта

```bash
git add .
git commit -m "что изменили"
git push
```
Amvera сам пересоберёт приложение.
