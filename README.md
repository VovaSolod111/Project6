# Восстановление пароля (Express + MySQL)

## Требования
- Node.js 18+
- MySQL
- Почтовый аккаунт и пароль приложения SMTP

## 1. Подготовить таблицу
В существующей БД `colledgebd` должна быть таблица `users` с полями `id_u`, `email`, `pass`, `forgotPass`. Если таблицы ещё нет, можно создать её так:

```sql
CREATE TABLE users (
  id_u INT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  email VARCHAR(255) NOT NULL UNIQUE,
  pass VARCHAR(255) NOT NULL,
  forgotPass TINYINT(1) NOT NULL DEFAULT 0
);
```

Если таблица уже создана, проверьте, что типы и названия столбцов совпадают. Не создавайте её повторно.

## 2. Настроить окружение
Скопируйте `.env.example` в `.env` и укажите реальные параметры MySQL и SMTP. Не публикуйте `.env` и не отправляйте его в репозиторий.

## 3. Запустить
```bash
npm install
npm start
```
Откройте `http://localhost:3000`.

## Как работает
1. `POST /forgotPassword` проверяет email в `users`, создаёт временный пароль, записывает его в `pass`, выставляет `forgotPass = 1` и отправляет письмо.
2. Страница `/changePassPage` отправляет email, временный пароль и новый пароль на `POST /changeNewPass`.
3. Второй обработчик принимает временный пароль только при `forgotPass = 1`, заменяет его новым паролем и сбрасывает флаг в `0`.

**Важно для реального сайта:** в учебном варианте код сохраняет пароли в том же формате, что и исходный проект. Для продакшена храните только стойкие хеши паролей (например, Argon2id/bcrypt), добавьте ограничение частоты запросов и срок действия временного пароля.
